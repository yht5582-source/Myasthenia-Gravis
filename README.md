# 重症肌無力決策台

重症肌無力（Myasthenia gravis）臨床分類、肌無力危機急診處置與免疫治療管理的互動網頁。

線上版：https://yht5582-source.github.io/Myasthenia-Gravis/

## 功能

1. **MGFA 分類與評估**：勾選眼肌與全身肌無力程度、主要受影響肌群、鼻胃管與插管狀態，自動判定 MGFA 臨床分類（I–V）；MG-ADL 八項計分；記錄血清型與胸腺狀態。
2. **肌無力危機急診處置**：
   - 呼吸評估：輸入體重、FVC、NIF、MEP、PaCO₂ 與床邊徵象，依 20/30/40 原則分流（一般病房、加護病房、建議插管）。
   - 誘因與膽鹼性危機鑑別、可疑藥物停用。
   - 血漿置換與 IVIG 選擇：依病人風險因子（敗血症、血行動態、血管通路、IgA 缺乏、腎功能、血栓風險、MuSK 抗體等）比較，並依體重與 Hct 計算血漿量與 IVIG 劑量。
   - 同步免疫治療與支持性照護、脫離呼吸器原則。
3. **免疫治療管理**：依 MGFA 國際共識判斷治療階段（未達標、難治型），建議胸腺切除、類固醇起始與減量、非類固醇免疫抑制劑與標靶生物製劑。
4. **用藥禁忌與文獻**：可能加重重症肌無力的藥物、肌無力危機與膽鹼性危機比較。

## 免責聲明

本工具為臨床決策輔助與教學用途，不能取代醫師完整評估。肌無力危機屬醫療急症，應依院內急重症流程處置；藥物劑量、禁忌與健保給付請以仿單、院內處方集及最新規定為準。
